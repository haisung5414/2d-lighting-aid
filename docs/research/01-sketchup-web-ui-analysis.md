# SketchUp Web UI 분석

> 출처: `reference/sketchUp/*.png` (2026-10-20 캡처, app.sketchup.com, 한국어 UI)
> 목적: lighting-aid를 "웹 기반 설계 도구"로 발전시킬 때 참고할 화면 구성과 상호작용 패턴을 정리한다.

---

## 0. 전체 흐름

```
[로그인 (Trimble Identity)] → [홈 / 파일 목록] → [모델링 작업 화면 (Editor)]
                                     ↑                       │
                                     └──── 햄버거 메뉴 > 홈 ───┘
```

SketchUp Web은 화면이 크게 세 단계로 나뉜다.

1. **인증 화면**: 별도 도메인(id.trimble.com)에서 처리한다.
2. **대시보드(홈)**: 클라우드에 저장된 파일을 관리한다.
3. **에디터**: 3D 뷰포트가 화면 전체를 차지하고, 모든 UI는 그 위에 떠 있는(floating) 패널로 배치된다.

## 1. 로그인 화면 (`login.png`)

| 영역 | 구성 |
|---|---|
| 좌측 약 2/3 | 브랜드 일러스트(연한 하늘색 지구 그래픽, 기하 도형 장식) + 큰 슬로건 "Everything SketchUp..." |
| 우측 약 1/3 | 흰 배경 카드. 로고 → "환영" → **Google로 계속 진행** 버튼 1개 → "다른 방법 시도" 접이식 링크 |
| 우측 하단 | 도움말, 개인정보처리방침, 이용약관 링크와 저작권 표기 |

**관찰 포인트**
- 인증을 자체 앱이 아니라 **통합 ID 서비스(SSO)** 에 위임한다. 앱 본체는 인증 로직을 갖지 않는다.
- 소셜 로그인 하나만 크게 보여 주고, 나머지 방법은 접어 두어서 선택지를 줄였다.

```
│              │ [새로 만들기][▾] [기기에서 열기]      ⇅  ☰   │
│ ▌🏠 홈        │ 최근 파일                                     │
│  ⬡ Trimble   │ ┌────────┐ ┌────────┐ ┌────────┐              │
│    Connect   │ │썸네일   │ │썸네일   │ │썸네일   │              │
│              │ │제목     │ │제목     │ │제목     │              │
│              │ │수정일 ☁ │ │수정일 ☁ │ │수정일 ☁ │              │
│              │ │크기   ⋮ │ │크기   ⋮ │ │크기   ⋮ │              │
│ ⓢ 정보       │ └────────┘ └────────┘ └────────┘              │
└──────────────┴─────────────────────────────────────────────┘
```

| 요소 | 설명 |
|---|---|
| 좌측 내비게이션 | 홈 / Trimble Connect(클라우드 저장소). 선택 항목은 연한 파란 배경과 좌측 강조 막대로 표시한다. 하단에 "정보"를 둔다. |
| 페이지 제목 | "홈"을 파란 굵은 글씨로 표시한다. |
| 주요 액션 | **새로 만들기**(분할 버튼: 드롭다운으로 템플릿 선택) + **기기에서 열기**(로컬 파일 업로드). 둘 다 테두리 버튼(outline) 스타일이다. |
| 보기 옵션 | 우측에 정렬 버튼과 목록/그리드 전환 버튼이 있다. |
| 파일 카드 | 썸네일(모델의 마지막 시점을 렌더링한 이미지), 제목, 마지막 수정일, 클라우드 동기화 아이콘, 파일 크기, 더보기(⋮) 메뉴로 구성된다. |
| 배경 | 아주 연한 회색(#F2F2F5 계열) 위에 흰 카드를 올려 깊이감을 준다. |

## 3. 계정 메뉴 (`main_account.png`)

- 우측 상단 사람 아이콘을 누르면 오른쪽 가장자리에 **드롭다운 카드**가 열린다.
- 구성: 큰 아바타 → 이름 → "다음으로 로그인:" + 이메일(알약 모양 배경) → 계정 관리 / 앱 설정 / 업그레이드 / 로그아웃.
- 메뉴 항목은 가운데 정렬 텍스트이며, 구분선 없이 넓은 간격으로 배치되어 있다.

## 4. 에디터 기본 화면 (`cad_default.png`)

```
┌───────────────────────────────┐                         ┌──────────────┐
│ ☰  연습1  ✦  ↶  ↷   저장됨     │                         │ (HC) ↖  [공유]│
└───────────────────────────────┘                         └──────────────┘
┌──┐                                                        개체 정보 [▢]
│🔍│                                                        구성 요소 [▢]
├──┤                                                        도우미    [▢]
│⌃ │                                                        3D Warehouse[▢]
│↖ │ 선택                                                    재질      [▢]
│⌫ │ 지우개                  3D 뷰포트                         스타일    [▢]
│✎ │ 선 (그리기 그룹)          (화면 전체)                      태그      [▢]
│▱ │ 사각형                                                  그림자    [▢]
│⇧ │ 밀기/끌기                                                장면      [▢]
│✥ │ 이동                                                    표시      [▢]
│⟳ │ 회전                                                    부드럽게   [▢]
│⤢ │ 축척                                                    모델 정보  [▢]
│🎨│ 페인트                                                          
│⊕ │ 궤도                                                    
│✋│ 이동(팬)                                                 
│🔍│ 확대/축소                                                
│… │ 더보기                                                   
│⌄ │                                                        
└──┘                                                        
(?) (🌐) (🖱)  상하/좌우로 이동할 방향으로 끕니다.          측정 [__________] ⓢ
```

### 4-1. 상단 좌측 바 (파일 헤더)
- **햄버거 메뉴** → 파일 메뉴 패널을 연다(5절 참고).
- **파일 이름**("연습1")을 굵게 표시한다.
- **AI 아이콘(✦)**, **실행 취소/다시 실행**.
- **저장 상태 표시**("저장됨"): 자동 저장 방식이며, 별도 저장 버튼이 없다.

### 4-2. 상단 우측 바 (협업)
- 사용자 아바타(이니셜 원형 "HC"), 커서/참여자 아이콘, **공유** 버튼(파란 채움, 주요 CTA).

### 4-3. 좌측 세로 툴바 (도구)
- 맨 위에 **도구 검색(🔍)** 버튼을 따로 떼어 두었다.
- 그 아래 세로 목록: 위/아래 스크롤 화살표(⌃/⌄) 사이에 선택, 지우개, 선, 사각형, 밀기/끌기, 이동, 회전, 축척, 페인트, 궤도, 팬, 확대 등이 있다.
- 아이콘만 표시하며, 활성 도구는 **좌측 파란 막대 + 연한 배경**으로 강조한다.
- 아이콘 색은 기본적으로 파랑이고, 동작을 나타내는 부분(점, 화살표)은 빨강으로 포인트를 준다.
- 맨 아래 `…` 로 확장 도구 팔레트를 연다.

### 4-4. 우측 세로 패널 탭 (트레이)
- 아이콘 버튼이 세로로 나열되고, 각 버튼 왼쪽에 **흰 알약 모양 라벨**이 붙는다.
  - 개체 정보 / 구성 요소 / 도우미 / 3D Warehouse / 재질 / 스타일 / 태그 / 그림자 / 장면 / 표시 / 부드럽게·매끄럽게 / 모델 정보
- 라벨은 처음에 보이고, 패널을 열거나 시간이 지나면 아이콘만 남는 것으로 보인다(추정).

### 4-5. 하단 상태 바
- 좌측: 도움말(?), 언어/지역(🌐), 마우스 조작 안내(🖱).
- 중앙: **현재 도구의 사용법을 문장으로 안내**한다. 예: "상하/좌우로 이동할 방향으로 끕니다."
- 우측: **측정값 입력 상자(VCB)**. 도구에 따라 라벨이 "측정" → "길이" 등으로 바뀌며, 그리는 도중에 숫자를 직접 입력할 수 있다.

### 4-6. 뷰포트
- 하늘(그라데이션)과 지면(회색)이 있는 3D 원근 뷰.
- 빨간 축선(X축), 점선 가이드 라인, 사람 크기 기준 모델(스케일 인지용).
- 화면 하단 중앙에 워터마크 로고가 있다(무료 플랜).

## 5. 파일 메뉴 (`cad_left_option_toggle.png`)

햄버거를 누르면 좌측에서 **슬라이드 패널**이 열리고, 햄버거 아이콘은 ✕로 바뀐다.

| 그룹 | 항목 |
|---|---|
| 파일 | 홈, 새로 만들기, 열기 ›, 다른 이름으로 저장, 공유, 가져오기 ›, 내보내기 ›, 다운로드 › |
| (구분선) | |
| 설정 | 앱 설정, 위치 추가, 인쇄 |

- `›` 가 붙은 항목은 하위 메뉴가 있음을 나타낸다.
- 아이콘 + 텍스트 라벨 구조이며, 각 항목의 세로 간격이 넉넉하다.

## 6. 확장 도구 팔레트 (`cad_left_button_options.png`)

좌측 툴바에서 그룹(예: 그리기 도구)을 열면 **큰 그리드 팔레트**가 펼쳐진다. 아이콘 아래에 작은 글씨 라벨이 붙고, 가로 구분선으로 카테고리를 나눈다.

| 행 | 도구 |
|---|---|
| 1 | 올가미, 재질 샘플링 |
| 2 | 원, 2점 호, 호, 다각형, 3점 호, 파이, 자유 그림, 직사각형 회전, 3D 텍스트 |
| 3 | 오프셋, 따라가기, 대칭 이동, 외부 셸, 교차·결합·빼기·트리밍·분리(비활성은 회색) |
| 4 | 치수, 각도기, 축, 텍스트, 단면, 태그 |
| 5 | 확대/축소, 확대/축소 범위, 창 확대/축소, 카메라 위치 지정, 둘러보기, 걷기 |
| 6 | AI Render, AI Assistant |
| 하단 | **편집** 버튼(툴바 사용자 정의) |

- 현재 상황에서 쓸 수 없는 도구는 **비활성(회색)** 으로 표시하고 숨기지 않는다.
- 팔레트 우측 가장자리에 `⋮` 핸들이 있어 크기 조절이나 이동이 가능해 보인다.

## 7. 우측 패널 열린 상태 (`cad_left_button_options.png`, `cad_right_button_click.png`)

"태그" 버튼을 누르면 해당 아이콘 바로 옆(좌측)에 **플로팅 패널**이 열린다.

```
┌──────────────────────────────┐
│ 태그                     [◇] │ ← 패널 제목 + 패널 아이콘
├──────────────────────────────┤
│ 👁  ⊕  📁  ↓AZ  🏷  ♻         │ ← 패널 전용 액션 툴바
│ ┌──────────────────────────┐ │
│ │ 🔍 태그 검색...            │ │ ← 패널 내부 검색
│ └──────────────────────────┘ │
│          ───────             │ ← 로딩/스크롤 표시
└──────────────────────────────┘
```

- 패널은 뷰포트를 가리지만 **반투명이 아닌 흰 카드**이고, 패널 아래쪽의 다른 탭 버튼(그림자, 장면)은 그대로 보인다.
- 패널 헤더 → 액션 아이콘 줄 → 검색 → 목록이라는 **일관된 패널 문법**을 갖는다.

## 8. 도구 검색 (`cad_left_search_button.png`)

- 좌측 상단 🔍 를 누르면 툴바 오른쪽으로 **가로로 긴 검색창**이 열린다("검색...", 우측에 도움말 ?).
- 명령 팔레트(Command Palette) 패턴이다. 도구 이름을 몰라도 텍스트로 찾을 수 있다.

## 9. 디자인 언어 요약

| 항목 | 특징 |
|---|---|
| 레이아웃 | **캔버스 우선(canvas-first)**: 뷰포트가 100%를 차지하고, 모든 UI는 모서리에 붙은 플로팅 카드다. |
| 색상 | 흰 카드 + 연회색 배경, 주요 색은 짙은 파랑(#005F9E 계열), 아이콘 포인트는 빨강. |
| 모서리/그림자 | 작은 라운드(2–4px), 아주 약한 그림자. 평면적이고 실용적인 느낌. |
| 활성 표시 | 좌측 파란 세로 막대 + 연한 파란 배경(내비게이션, 툴바 공통). |
| 라벨 전략 | 툴바는 아이콘만, 우측 트레이는 아이콘 + 알약 라벨, 확장 팔레트는 아이콘 + 작은 라벨. |
| 안내 | 상태 바에 "지금 무엇을 하면 되는지"를 문장으로 보여 준다. |
| 입력 | 그리기 도중 정확한 수치를 입력하는 VCB 상자. |
| 저장 | 자동 저장 + "저장됨" 상태 텍스트. |
| 협업 | 아바타, 공유 버튼을 우측 상단에 고정. |

## 10. lighting-aid에 바로 의미가 있는 패턴 (요약)

1. 캔버스 우선 레이아웃과 플로팅 패널.
2. 좌측 도구 / 우측 속성·라이브러리 패널이라는 역할 분리.
3. 하단 상태 바의 도구 안내 문장과 수치 입력 상자.
4. 홈(파일 목록) ↔ 에디터라는 2단 구조, 썸네일 카드.
5. 명령 검색(도구 검색).
6. 자동 저장 상태 표시.

자세한 적용 방안은 `03-lighting-aid-sketchup-mapping.md`에서 다룬다.
