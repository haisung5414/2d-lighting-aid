# SketchUp Web 에디터: 좌우 구성과 분류 기준

> 근거: `reference/sketchUp/` 스크린샷 + SketchUp 공식 도움말 (2026-10-20 확인)

## 핵심: 좌우를 나눈 기준

**왼쪽은 "무엇을 할지(동사)", 오른쪽은 "무엇을 보고 관리할지(명사)"이다.**

| | 왼쪽: 도구 (Tools) | 오른쪽: 패널 (Panels) |
|---|---|---|
| 성격 | 캔버스에서 **직접 실행하는 동작** | 모델의 **정보, 자원, 설정** |
| 동작 방식 | 한 번에 **하나만 활성화**된다. 고른 도구에 따라 마우스 클릭의 의미가 바뀐다. | 여러 개를 열어 둘 수 있고, 마우스 동작에는 영향을 주지 않는다. |
| 대상 | 지금 그리고 있거나 손대는 형상 | 선택한 개체, 또는 모델 전체 |

## 왼쪽: 도구

**메인 툴바** (자주 쓰는 도구만 모아 두었고, 사용자가 편집할 수 있다)
- 맨 위: 도구 검색
- 선택·삭제: 선택(Space), 지우개(E)
- 그리기: 연필/선(L), 사각형(R)
- 수정: 밀기/끌기(P), 이동(M), 회전(Q), 축척(S), 페인트(B)
- 측정: 줄자(T)
- 시점: 궤도(O), 팬(H)
- 맨 아래: `…` 버튼으로 확장 도구 세트를 연다.

**확장 도구 세트** (스크린샷 기준, 같은 종류끼리 줄을 나눠 놓았다)
- 선택 보조: 올가미, 재질 샘플링
- 그리기: 원, 호(종류별), 다각형, 파이, 자유 그림, 3D 텍스트
- 형상 편집: 오프셋, 따라가기, 대칭 이동, 솔리드 연산(교차, 결합, 빼기 등)
- 주석·보조: 치수, 각도기, 축, 텍스트, 단면, 태그
- 카메라: 확대/축소, 범위 확대, 카메라 위치, 둘러보기, 걷기
- AI: AI Render, AI Assistant

왼쪽 안에서도 **선택 → 그리기 → 수정 → 측정 → 시점** 순서로, 작업 흐름을 따라 배치되어 있다.

## 오른쪽: 패널

공식 도움말 기준 16개. 위에서 아래로 갈수록 **선택한 개체 → 자원 → 모델 전체 → 설정**으로 범위가 넓어진다.

| 그룹 | 패널 | 역할 |
|---|---|---|
| 선택한 개체 | 개체 정보 (Entity Info) | 선택한 것의 속성(재질, 태그 등) |
| | 아웃라이너 (Outliner) | 모델 구조를 트리로 보여 줌 |
| | 댓글 (Comments) | 협업 코멘트 |
| 도움 | 도우미 (Instructor) | **현재 도구**의 사용법 안내 |
| 자원 라이브러리 | 3D Warehouse, 구성 요소, 재질 | 가져다 쓰는 재료 |
| 모델 전체의 표현 | 스타일, 환경, 그림자, 부드럽게/매끄럽게, 표시 | 화면에 어떻게 보이는지 |
| 정리·저장된 상태 | 태그, 장면 | 보이기/숨기기 그룹, 저장해 둔 시점 |
| 모델 설정·검사 | 모델 정보, 솔리드 검사 | 단위, 글꼴 등 기본 설정과 오류 검사 |

## 기준이 갈리는 경계 사례

- **"태그"는 양쪽에 다 있다.** 왼쪽 확장 도구의 태그는 "클릭해서 태그를 붙이는 **동작**"이고, 오른쪽 태그 패널은 "태그 목록을 **관리**"한다. 같은 개념이라도 동사냐 명사냐에 따라 위치가 갈린다.
- **"도우미"는 오른쪽에 있지만 왼쪽 도구에 종속된다.** 내용은 현재 도구를 따라 바뀌지만, 정보를 보여 주는 것이라 패널로 분류했다.
- **카메라는 왼쪽이다.** 궤도와 팬은 모델을 바꾸지는 않지만, 마우스 드래그의 의미를 바꾸는 모드이기 때문에 도구로 분류된다. 반면 저장된 시점(장면)은 오른쪽에 있다.

상단(파일 이름, 실행 취소, 저장 상태, 공유)과 하단 상태 바(도구 안내 문장, 수치 입력 상자)는 좌우 어느 쪽에도 속하지 않는 별도 영역이다.

## lighting-aid에 대입하면

- **왼쪽(동작)**: 선택, 조명 배치, 조준, 셔터, Probe 이동, 측정, 팬·줌
- **오른쪽(정보·관리)**: 조명 정보, 조명 목록, 조명기 라이브러리, 씬, 표시, 채널 패치, 무대 정보
