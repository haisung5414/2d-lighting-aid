개인정보 처리방침

조명 시뮬레이터 · 시행일 2026년 10월 21일

조명 시뮬레이터(이하 "앱")는 학생 연극 동아리가 무대 조명을 계획할 때 쓰는 비영리 웹 앱입니다. 이 문서는 앱이 어떤 정보를 왜 받고, 어떻게 보관하는지 설명합니다.

1. 로그인하지 않고 쓸 때

로그인하지 않으면 앱은 개인정보를 받지 않습니다. 작업 파일은 사용자의 컴퓨터에 JSON 파일로만 저장됩니다. 보기 설정 같은 일부 화면 설정은 브라우저의 저장소(localStorage)에 남습니다.

2. Google로 로그인할 때 받는 정보

  • Google 계정의 이름, 이메일 주소, 프로필 사진 주소
  • 로그인 상태를 유지하기 위한 인증 정보(세션)

앱은 Google 계정의 비밀번호를 받지 않으며, Gmail·드라이브·캘린더 같은 다른 Google 데이터에 접근하지 않습니다.

3. 온라인에 저장하는 정보

사용자가 "온라인에 저장"을 누르면, 작업 이름과 작업 내용(조명·세트·씬 배치 등, 내 컴퓨터에 저장하는 파일과 같은 내용)이 저장됩니다. 각 작업은 저장한 사람의 계정에만 연결되며, 다른 사용자는 읽거나 고칠 수 없습니다.

4. 이용 목적

받은 정보는 로그인한 사람을 구분하고, 그 사람의 작업을 저장하고 다시 불러오는 데에만 씁니다. 광고, 분석, 판매, 제3자 제공에는 쓰지 않습니다.

5. 보관 장소와 처리 위탁

로그인과 온라인 저장은 Supabase의 서비스를 이용하며, 데이터는 Supabase가 운영하는 서버(호주 시드니 지역)에 보관됩니다. 로그인 과정은 Google이 처리합니다. 앱 화면은 GitHub Pages에서 제공됩니다.

6. 보관 기간과 삭제

  • 온라인에 저장한 작업은 사용자가 지울 때까지 보관합니다. 작업 목록에서 직접 지울 수 있습니다.
  • 계정 정보(이름, 이메일 등)까지 모두 지우고 싶다면 아래 문의처로 요청해 주세요. 확인 후 계정과 그 계정의 작업을 모두 삭제합니다.
  • 앱 운영을 끝내면 저장된 정보를 모두 삭제합니다.

7. 문의

개인정보에 관한 문의와 삭제 요청은 GitHub 저장소의 Issues에 남겨 주세요. 이메일 주소처럼 공개되면 안 되는 내용은 Issues에 적지 마세요.

8. 바뀔 때

이 방침이 바뀌면 이 페이지에 새 내용과 시행일을 적습니다.
