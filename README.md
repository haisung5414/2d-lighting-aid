# 조명 시뮬레이터 2D (2d-lighting-aid)

연극 동아리와 조명 디자이너가 설치 없이 브라우저에서 무대 조명을 설계하는 도구입니다.
평면도에 조명·세트·사람 모형을 놓고, 실측 광도 모델로 바닥과 배우 얼굴의 밝기와 색을 계산해 2D와 3D로 보여 줍니다.
서버 없이 동작하며, 작업은 JSON 파일로 저장하고 불러옵니다.

## 실행

```bash
npm install
npm run dev
```

`npm run build`는 타입 검사(`tsc`) 뒤 `dist/`에 정적 파일을 만듭니다. main 브랜치에 push하면 GitHub Pages로 배포됩니다.

## 사용법 요약

* 처음 화면에서 작업 공간(Sandbox, Humanities)을 고르거나 저장한 파일을 불러옵니다.
* 왼쪽 도구: 선택(Space), 엘립소이달(E), 프레넬(F), PAR(P), 세트 그리기(R), 벽(W), 덧마루(D), 애플박스(B), 사람 모형(A). 놓은 뒤에는 선택 도구로 돌아옵니다.
* 조명을 누르면 오른쪽 위에 "조명 설정"(렌즈, 젤, 디머, 셔터, 3D 그림자)이 펼쳐집니다. 세트와 사람 모형은 "선택한 객체 속성"에서 고칩니다. 두 번 누르면 언제든 열립니다.
* 끈 직후나 세트를 놓은 직후 숫자를 치고 Enter를 누르면 정확한 거리나 높이가 됩니다 (예: 2.5, 900mm).
* 아래 씬 서랍에서 씬을 만들고 순서를 바꿉니다. 아래 상태 바 왼쪽의 `?` 버튼을 누르면 도우미 패널에 단축키가 나옵니다.
